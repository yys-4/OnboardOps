### Panduan Mengambil Screenshot di IBM Bob IDE:
1. Pada panel sebelah kanan di **IBM Bob IDE**, klik tab **Tasks** (ikon list/task).
2. Pilih task yang terkait dari list task Anda.
3. Klik pada **task header** di bagian atas chat panel untuk menampilkan dialog **Task session consumption summary** (menampilkan token consumption & breakdown).
4. Ambil screenshot jendela/dialog tersebut dalam format PNG.
5. Simpan file screenshot ke dalam direktori `bob_sessions/` ini dengan format nama di atas.
